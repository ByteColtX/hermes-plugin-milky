# Spec Delta

## ADDED Requirements

### Requirement: 群管配置必须显式启用并具有可验证默认值

系统 MUST 增加普通配置 MILKY_MODERATION_POLICY；原生设置使用对象，兼容环境输入使用等价 JSON，二者执行相同完整校验。未配置时 MUST 禁用群管；groups 按完整且具体的 group:<id> 指定，禁止 dm、temp 和通配符，最多 100 群。每群 enabled 默认 false，mode 只接受 auto/smart/manual，启用后 mode 默认 auto。每群 MUST 有版本化群规、带稳定 ID 的本地字面词/精确例外/受限格式或刷屏规则，以及有限动作政策；空群规或无有效筛查规则不得启用。

动作政策 MUST 默认允许撤回与禁言、禁止踢人及拒绝再次申请，禁言默认 300 秒且自动上限 300 秒；时长只能为不含布尔值的正整数且不超过 7200 秒。上下文 N 默认 20、允许 1 至 100，历史窗口默认 600 秒、允许 1 至 3600 秒；单条/总正文分别不超过 4000/20000 字符。模型超时默认 30 秒、允许 1 至 120 秒；辅助模型提供方及模型使用宿主独立辅助配置，不把密钥纳入本设置。方案有效期 600 秒、消息接纳时窗 24 小时、内存案件正文最长 600 秒、独立短期证据最长 24 小时且每 profile 不超过 64 MiB，以及并发/容量上限遵守 group-moderation 规范，不接受关闭这些边界的值。

配置 MUST 拒绝未知字段、非法类型、重复规则 ID、越界值、无上限匹配表达式及非法群 key，不静默回退为自动执行。规则文本仅作配置和复核输入，不是可执行指令。全部普通来源均缺少该配置时不影响既有聊天启动。

#### Scenario: 现有用户升级

- **WHEN** 现有 profile 没有群管设置，即使普通入站白名单为空或包含 group:*
- **THEN** 系统 SHALL 保持群管关闭；用户显式启用具体群后默认模式才为 auto

#### Scenario: 不完整或非法策略

- **WHEN** 启用群缺少群规、规则引用不存在、mode 不合法或时长越界
- **THEN** 系统 SHALL 在保存或启动时拒绝候选并指出安全字段分类，不以默认策略处罚

### Requirement: 群管策略保存和运行生效必须分离

群管普通设置 MUST 沿用宿主 profile 来源优先级、保存核验和启动快照；Web 保存 MUST 显示待重载，只有运行实例确认后才能显示有效版本。群管案件 MUST 绑定作出决定的有效策略版本；重载后版本不符的批准 MUST 失效，未发送步骤重新复核。执行仍 MUST 重查当前有效入站范围，不能将持久化但未生效的策略当成运行事实。

#### Scenario: 保存关闭但尚未重载

- **WHEN** 操作者保存 enabled=false，而运行实例尚未确认重载
- **THEN** 页面 SHALL 显示已保存、待重载以及当前有效状态，不宣称已停止处罚

#### Scenario: 重载改变策略

- **WHEN** 新实例确认有效群管策略版本与待执行方案不一致
- **THEN** 系统 SHALL 阻止旧批准执行，案件显示需要重新复核
